# Добавленный функционал

Функционал, добавленный в портативную версию относительно оригинала автора,
вместе с новыми зависимостями пакетов.

## Портативный лаунчер

`start.exe` и его исходник: обычный старт, старт с дебагом, обслуживание
(очистка пользовательских данных, временных файлов исполнения, кэша),
35 языков, тултипы, диалог с кодом ошибки.
Зависимости: нет.

## Портативный Python-рантайм

`python/`: CPython 3.14.7 со всеми зависимостями программы внутри,
менеджер пакетов pip, манифест `python/INSTALLED_PACKAGES.txt`.
Зависимости: комплект из 62 пакетов.

## Папка пользовательских данных

`data_user/`: настройки, модели, секреты и логи хранятся внутри папки
программы.
Зависимости: нет.

## Папка кэша

`cache/`: пересоздаваемые кэши и временные файлы внутри папки программы
(pip, uv, Hugging Face, домашняя папка клиентов, temp).
Зависимости: нет.

## Комплект документации

`portable.md` с языковыми версиями; этот журнал и журнал удалённого
на трёх языках.
Зависимости: нет.

## Каталог ASR-моделей пользователя

Двенадцать transcribe.cpp Vulkan GGUF моделей (gigaam-v3, parakeet-tdt-0.6b-v3,
qwen3-asr-0.6b, qwen3-asr-1.7b; q8_0/q6_k/f16) из репозиториев пользователя на
Hugging Face и ModelScope. Единый каталог описывает источники и файлы
(размер + SHA-256), проверка хеша — при установке и явной проверке целостности.
Зависимости: modelscope, modelscope-hub.

## Выбор локальной модели

Активная модель локального распознавания (включая вариант квантизации)
выбирается в карточке «Модель ASR»: все двенадцать моделей каталога в каждом
кванте плюс пункт «Не выбрано»; все модели каталога устанавливаются по
требованию.
Зависимости: нет.

## Состояние «Не выбрано»

В каждом выборе настроек, который может быть пустым, есть отдельный пункт
«Не выбрано» (или его аналог на языке интерфейса), и после чистой загрузки он
выбран по умолчанию. Пока настройка канала (распознавание речи, распознавание
собеседника, перевод, модель ASR) не выбрана, канал не готов: его кнопка на
панели отключена, нажатие ничего не делает, ошибок и подсказок не появляется.
OSC-зеркало публикует состояние «Не выбрано» как id 255.
Зависимости: нет.

## Выбор устройства ASR

Настройка «Устройство ASR» выбирает видеокарту для модели распознавания или
CPU; CPU включает CPU-бэкенд transcribe.cpp и для своего канала, и для канала
собеседника. Тот же список устройств предлагается для переводческого
рантайма.
Зависимости: нет.
