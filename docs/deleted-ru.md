# Удалённый функционал

Функционал, удалённый из портативной версии относительно оригинала автора,
вместе с зависимостями пакетов, которые ушли с ним.

## Managed control-plane (broker)

Сервис broker (Cloudflare Worker), его deploy, миграции и тесты.
Зависимости: нет (Node/pnpm-обвязка ушла вместе с ним).

## Установщик и сборка

Установщик Inno Setup, провизия моделей установщиком, build spec.
Зависимости: нет.

## Сборочная и CI-обвязка

GitHub CI, скрипты, pnpm-манифесты, tsconfig, vitest, конфиг Rust-тулчейна.
Зависимости: нет.

## Авторская документация

AGENTS.md, CODE_SIGNING.md, PRIVACY.md, README.md.
Зависимости: нет.

## Внешние кэши пакетов

Кэши pip и uv вне папки программы.
Зависимости: нет.

## Облачное распознавание речи

Провайдеры STT Deepgram, Gemini Transcribe и ElevenLabs Scribe с проверкой
API-ключей, сопоставлением языков и ротацией бесплатных тарифов между ними
(модули адаптеров удалены).
Зависимости: deepgram-sdk, elevenlabs, google-genai, google-auth, pyasn1,
pyasn1-modules, distro, tenacity.

## Облачный провайдер перевода (Gemini)

Провайдер LLM Gemini с проверкой API-ключа (модуль адаптера удалён).
Зависимости: google-genai (также удалён с облачным распознаванием речи).

## Шифрование секретов

Fernet-хранилище секретов, хранилище Windows Credential Manager (keyring) и
RSA-проверка ID-токена при входе в аккаунт; теперь секреты хранятся открытым
текстом.
Зависимости: cryptography, keyring, pywin32-ctypes, jaraco.classes,
jaraco.context, jaraco.functools, more-itertools.

## Облачные провайдеры перевода

DeepSeek, Qwen (DashScope), OpenAI, OpenRouter, бэкенд ChatGPT и публичный
API index-translate: модули провайдеров удалены. Перевод работает через
локальный OpenAI-совместимый endpoint или локальный рантайм Gemma.
Зависимости: нет (только код).

## Платное облачное распознавание речи

Soniox (реальное время), Qwen Audio (DashScope) и пользовательское
STT-подключение с проверкой их API-ключей. Локальные CPU-провайдеры также
удалены; распознавание остаётся на единственном локальном провайдере Qwen3
ASR (transcribe.cpp).
Зависимости: нет (только код).

## Входы в аккаунты и managed-ключи

QQ-логин, Discord OAuth, ChatGPT OAuth и OpenRouter PKCE OAuth вместе с
выдачей managed-ключей через брокера автора и подписью managed identity;
карточки аккаунта и входа удалены из интерфейса настроек.
Зависимости: нет (только код).

## Телеметрия активности по дням

Ежедневный пинг активности на брокер и легаси-учёт дат успешных переводов
в миграции настроек.
Зависимости: нет (только код).

## Каталог ASR-моделей автора

ASR-модели автора (orukeet, fun-asr nano/mlt, японский parakeet sherpa,
qwen3-asr-1.7b Q6_K) и их манифесты с закреплёнными sha256 заменены каталогом
GGUF-моделей пользователя с упрощёнными манифестами.
Зависимости: нет (только код).

## Путь распознавания sherpa/ONNX

Бэкенд распознавания sherpa-onnx (японский parakeet), его Windows-рантайм и
команда проверки рантайма.
Зависимости: sherpa-onnx, sherpa-onnx-core.

## Чистка интерфейса настроек

Карточки и элементы управления удалённых функций удалены из интерфейса
настроек: карточка аккаунта ChatGPT, карточка managed-ключа с индикатором
пробного периода, карточка пользовательского STT-подключения, раздел API-ключей
с десятью облачными полями, регион Qwen и поле API-хоста, переключатель
телеметрии и кнопка OpenRouter PKCE. Оставшиеся карточки (Local LLM,
устройства GPU, модель ASR, HTTP-расширение) показываются только когда
соответствующая настройка выбрана.
Зависимости: нет (только интерфейс).

## Рекламные поверхности

Снэкбар «звезда на GitHub» и его запуск после старта, диалог письма
основателя с триггерами тёплого документа, кнопка справки по API-ключам и
промо-хук успешного перевода в конвейере событий.
Зависимости: нет (только интерфейс).
