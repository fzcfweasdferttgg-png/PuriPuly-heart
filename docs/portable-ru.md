# PuriPuly Heart — портативная версия

Самодостаточная сборка: не требует установленного Python и ничего не оставляет
за пределами папки. Папку можно переносить на другой диск или компьютер —
запуск работает относительно её расположения, имя папки не зашито нигде.

## Запуск

`start.exe` — единственный файл запуска, без параметров:

- **Запустить** — обычный старт, без лишних окон;
- **Запустить с дебагом** — консоль рантайма Python + отладочные элементы
  в интерфейсе программы (ключ `--debug-ui-preview`);
- **Обслуживание** — работа с данными без запуска программы:
  - **Очистить пользовательские данные** — удаляет всё содержимое `var/data_user`;
  - **Очистить временные файлы исполнения Python** — удаляет `__pycache__`
    (скомпилированный код; используйте после изменения кода, чтобы программа
    не следовала старому кэшу);
  - **Очистить кэш** — удаляет всё содержимое `var/cache`
    (пересоздаваемые кэши: скачанные пакеты, кэши клиентов, временные файлы;
    восстанавливаются автоматически);
- **Выход**.

Пояснения к пунктам показываются при наведении. Язык интерфейса лаунчера
определяется языком Windows, встроено 35 языков.

Замечания: если программа завершилась с ошибкой сразу после обычного старта,
лаунчер покажет диалог с кодом (для диагностики используйте дебаг). Результат
очистки с ошибками означает, что часть файлов занята — закройте программу и
повторите. Одновременно может быть открыто только одно окно лаунчера.

Секреты и API-ключи хранятся открытым текстом в `var/data_user/` — шифрование
намеренно не используется.

## Структура

- `start.exe`, `start.cs` — лаунчер и его источник (UTF-8)
- `src/` — код программы (запускается прямо из источников)
- `runtime/python/` — портативный Python 3.14 + все зависимости (`Lib/site-packages`)
- `runtime/.venv/` — среда разработки и тестов
- `native/build/` — нативный рантайм распознавания: ASR-воркер, transcribe.cpp, ggml-бэкенды
- `native/third_party/` — уведомления лицензий, шрифты, OpenVR
- `native/` — исходники Rust-компонентов (оверлей и др.)
- `var/data_user/` — все пользовательские данные: настройки, модели, секреты, логи
- `var/cache/` — пересоздаваемые кэши и временные файлы (можно удалять)
- `docs/prompts/` — шаблоны промптов (данные рантайма)
- `docs/` — portable-руководства и журналы added/deleted (три языка)
- `scripts/`, `pyproject.toml`, `uv.lock`, `LICENSE` — сборочные скрипты, манифесты зависимостей, лицензия
- `tests/` — тесты

## Переносимость и изоляция

- Интерпретатор и все зависимости лежат в `runtime/python/`; системный Python
  не используется и не затрагивается.
- `runtime/python/python314._pth` задаёт пути: стандартная библиотека, свои
  `Lib/site-packages`, источники `../../src`. Чужие переменные окружения
  (`PYTHONPATH`, `PYTHONHOME`) игнорируются, пользовательский site-packages
  не подмешивается.
- Реестр, PATH и файловые ассоциации не изменяются.
- Данные приложения всегда в `var/data_user/` внутри папки.
- Все пересоздаваемые кэши (pip, uv, клиент Flet, Hugging Face, временные
  файлы) лежат в `var/cache/` внутри папки; `var/data_user/` — только пользовательские данные.

## Управление пакетами

Пакеты управляются только портативным интерпретатором:

```
runtime\python\python.exe -m pip install <пакет>
runtime\python\python.exe -m pip install -U <пакет>
runtime\python\python.exe -m pip uninstall <пакет>
```

Всё остаётся внутри папки: код и метаданные пакетов в
`runtime/python/Lib/site-packages`, шимы точек входа в `runtime/python/Scripts`,
скачанный кэш — в `var/cache/pip`. Интерпретатор не затрагивает системные
установки Python. `runtime/python/INSTALLED_PACKAGES.txt` содержит список
поставляемых пакетов.

## Пересборка лаунчера

Команда выполняется из корня портативной папки:

```
%SystemRoot%\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /codepage:65001 /target:winexe /platform:anycpu /optimize+ /r:System.dll /r:System.Drawing.dll /r:System.Windows.Forms.dll /r:System.Core.dll /win32icon:src\puripuly_heart\data\icons\icon.ico /out:start.exe start.cs
```

Флаг `/codepage:65001` обязателен: исходник в UTF-8 (35 языков).
