# 추가된 기능

저자 원본 대비 휴대용 버전에 추가된 기능과 새 패키지 의존성입니다.

## 휴대용 런처

`start.exe`와 그 소스: 일반 시작, 디버그 시작, 유지 관리(사용자 데이터,
실행 임시 파일, 캐시 정리), 35개 언어, 툴팁, 오류 코드 대화 상자.
의존성: 없음.

## 휴대용 Python 런타임

`python/`: 프로그램의 모든 의존성이 포함된 CPython 3.14.7, 패키지 관리자
pip, `python/INSTALLED_PACKAGES.txt` 목록.
의존성: 62개 패키지 세트.

## 사용자 데이터 폴더

`data_user/`: 설정, 모델, 비밀, 로그가 프로그램 폴더 안에 저장됩니다.
의존성: 없음.

## 캐시 폴더

`cache/`: 재생성 가능한 캐시와 임시 파일이 프로그램 폴더 안에 유지됩니다
(pip, uv, Hugging Face, 클라이언트 홈, temp).
의존성: 없음.

## 문서 세트

`portable.md`와 언어 버전들, 이 문서와 삭제 기록(3개 언어).
의존성: 없음.

## 사용자 ASR 모델 카탈로그

transcribe.cpp Vulkan GGUF 모델 12개(gigaam-v3, parakeet-tdt-0.6b-v3,
qwen3-asr-0.6b, qwen3-asr-1.7b; q8_0/q6_k/f16)를 사용자의 Hugging Face 및
ModelScope 저장소에서 사용합니다. 간소화된 v2 매니페스트가 소스와 파일을
크기 + CRC32로 기술하며 검증은 설치 시에만 수행됩니다.
의존성: modelscope, modelscope-hub.

## 로컬 모델 선택

활성 로컬 인식 모델(양자화 변형 포함)은 설정의 "ASR 모델" 카드에서
선택합니다: 카탈로그의 열두 모델을 모든 양자화와 함께, 그리고 "선택 안
됨" 항목을 제공하며, 카탈로그의 모든 모델은 필요할 때 설치할 수 있습니다.
의존성: 없음.

## "선택 안됨" 상태

비어 있을 수 있는 모든 설정 선택에는 별도의 "선택 안됨" 항목(또는 해당
언어의 동등한 표현)이 있고 첫 로드 후 기본 상태입니다. 채널 설정(음성 인식,
상대방 인식, 번역, ASR 모델)이 선택되지 않은 동안 채널은 준비되지 않은
상태입니다: 패널의 버튼이 비활성화되고 눌러도 아무 일도 일어나지 않으며
오류나 안내가 표시되지 않습니다. OSC 미러는 "선택 안됨" 상태를 id 255로
게시합니다.
의존성: 없음.

## ASR 장치 선택

"ASR 장치" 설정은 인식 모델을 돌릴 비디오 카드 또는 CPU를 고릅니다. CPU는
transcribe.cpp의 CPU 백엔드를 자기 채널과 상대방 채널 모두에 활성화합니다.
같은 장치 목록이 번역 런타임에도 제공됩니다.
의존성: 없음.
